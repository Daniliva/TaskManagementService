# Готовая реализация (для подсказок)

Это то, что нужно, чтобы красные тесты стали зелёными. Не копируйте целиком — сначала попробуйте реализовать сами по
[docs/IMPLEMENTATION-SPEC.md](../docs/IMPLEMENTATION-SPEC.md).

* `files/` — файлы с реализацией; пути повторяют структуру репозитория (`reference/files/X` соответствует `X`).
* `implementation-on-top-of-spec.patch` — то же одним патчем. Применить всё сразу: `git apply reference/implementation-on-top-of-spec.patch`
  (патч не трогает папку `reference/`, документацию и README).

Папку `reference/` можно удалить, когда реализация написана.
